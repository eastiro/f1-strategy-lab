# Reports Guide

This folder keeps research artifacts separate from raw source data and application code.

- `research/`: readable methods, protocols, diagnostics, and research summaries.
- `results/`: reproducible CSV outputs from the validation and audit scripts.
- `presentation/`: portfolio wording and the two-minute silent-demo kit.
- `figures/`: generated visual exports when they are needed; this directory is intentionally ignored by Git.

For the quickest project overview, start with `research/v2_research_summary.md`.
